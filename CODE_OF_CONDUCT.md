# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and inclusive, give and accept constructive feedback gracefully, and focus
on what is best for the team and the community. Harassment, discriminatory language, personal
attacks and publishing others' private information are not tolerated.

The event's own code of conduct and the organisers' instructions apply on hackathon day.

## Enforcement

Report unacceptable behaviour privately to the repository maintainers (via GitHub, or in person on
the day). Reports are handled confidentially, and maintainers may take any action they deem
appropriate, including removal from the project.
